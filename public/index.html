Data sources

Borrower financials

A CSV with one row per borrower and quarter. Required columns: record_id, borrower_id, period (for example 2026-Q3), currency (USD), debt_usd, ttm_ebitda_usd, ttm_debt_service_usd, ttm_available_cashflow_usd, max_leverage, min_dscr. Maximum 4 MB.

Loan policy

A TXT file is read as-is. A PDF is sent to the LlamaParse document parser if the server has a key; on this public demo PDF parsing is switched off. You review the text before any test runs. Maximum 3 MB.

Review the extracted policy text

Compare this with the signed agreement. Parsers can misread tables and numbers. You can edit the text before running the tests.
